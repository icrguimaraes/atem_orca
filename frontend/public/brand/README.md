# Marca do Grupo Atem

- `logo.png`: logo oficial com fundo transparente (tema claro) — usada no login.
- `logo-dark.png`: mesma logo com o texto em branco (tema escuro).
- `logo-atem.png` / `logo-atem-claro.png`: versões compactas da Prévia de Resultados (06/11/2026), usadas na barra

Gerados a partir da imagem fornecida pelo cliente (200 px, JPEG). Se chegar o arquivo vetorial (SVG/AI),
substitua os arquivos e mantenha os nomes; `components/Brand.tsx` e o CSS escolhem a variante pelo tema.
